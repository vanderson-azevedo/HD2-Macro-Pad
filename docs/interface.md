# 🖥️ Interface

A interface é composta por três áreas principais:

```text
┌─────────────────────────────────────┐
│  🔱 HD2 Stratagems                  │
├─────────────────────────────────────┤
│                                     │
│  🦅 Eagle                           │
│  [card] [card] [card]               │
│                                     │
│  🛸 Orbital                         │
│  [card] [card] [card]               │
│                                     │
│  ...                                 │
├─────────────────────────────────────┤
│  [S1][S2][S3][S4][S5][S6][S7]      │
│      [S8][S9][S10][S11]             │
└─────────────────────────────────────┘
```

## Lista de Stratagems

A lista é organizada por categorias e pode ser percorrida por rolagem.

## Loadout

O loadout permanece fixo na parte inferior da interface.

## Modal de busca

Ao clicar em um slot vazio, é aberto um modal com campo de busca:

```text
┌─────────────────────────────────────┐
│ 🔍 [buscar stratagem...]       [✕] │
├─────────────────────────────────────┤
│ [card] [card] [card]                │
│ [card] [card] [card]                │
│ ...                                 │
└─────────────────────────────────────┘
```

A busca permite localizar rapidamente um Stratagem pelo nome.
